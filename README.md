# npg-marcenaria

Demonstração comercial da NPG Marcenaria, em Campo Magro, Paraná. Projeto independente derivado do template de móveis, com identidade, ritmo e fotografia próprios.

Não é o site oficial. Contato por Instagram até WhatsApp, telefone, e-mail e endereço serem confirmados.

## Design Read

Landing institucional de prospecção para clientes finais e profissionais de interiores, com linguagem contemporânea de marcenaria de precisão.

Dials: DESIGN_VARIANCE 7 / MOTION_INTENSITY 4 / VISUAL_DENSITY 3

## Stack

- Vite 8
- React 19
- TypeScript
- Tailwind CSS 4
- Motion
- Phosphor Icons
- Outfit Variable

SPA de uma página. Sem backend. `noindex, nofollow`.

## Requisitos

- Node.js 20+
- npm

## Instalacao

```bash
cd npg-marcenaria
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Onde editar

| Arquivo | O que muda |
| --- | --- |
| `src/config/site.ts` | Empresa, contato, Instagram, SEO, rating Google |
| `src/config/content.ts` | Hero, projetos, execução, soluções, prova social, CTAs |
| `src/config/design.ts` | Preset, tokens, seções on/off, motion |
| `public/npg/` | raw, optimized e branding |

## Assets

Originais em `public/npg/raw/`. Não sobrescrever. Cópias de uso em `public/npg/optimized/` e `public/npg/branding/`.
